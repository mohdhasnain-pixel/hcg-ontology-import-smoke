# hcg ontology import smoke fixtures

Synthetic fixtures for testing Context AI's Git import, one folder per format:
`dbt-semantic`, `cube-yaml`, `atscale-sml`, `hcg-schema-json`, `owl-turtle`, `json-ld`, `rdf-xml`.
`hostile-rdf-xml` holds a nested-entity RDF/XML file that the import must refuse.

No real or customer data. Temporary repository; it will be deleted after the test.
